# IzTap AI — Responsive React Frontend

40 client-side routes, mobile/desktop responsive, Russian UI. AI matching, QR scanning, TastaMat lockers, payment and bonus functions are demonstrative and not connected to real services.

Run: `npm install` then `npm run dev`.

GitHub Pages setup: Settings > Pages > Build and deployment > GitHub Actions. Workflow automatically builds and deploys.

Site: https://didar-kz.github.io/iztap-ai-demo/

Design file: https://www.figma.com/design/yqRXg0VWwd4v3U2zutR5Vw
